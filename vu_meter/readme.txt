Overview
--------
VUMeter is an old style analog meter which can be used to monitor sound
levels. Right click on the meters to display a menu of program options.


System requirements
-------------------
Microsoft Windows Vista or 7

History
-------
· version 1.2 (23 March 2010) ·
rewrote the program using the Core Audio and Direct2D APIs

window resizing has been implemented

· version 1.1 (11 July 2006) ·
updated the performance to be more indicative of a true VU meter
added the option to adjust the 0VU level from -30 to 0dBFS
